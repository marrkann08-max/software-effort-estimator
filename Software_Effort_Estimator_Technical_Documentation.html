Prediction interval

Signed relative error is (prediction - actual) / actual. The empirical interval is [prediction / (1 + q90), prediction / (1 + q10)], using pure outer-fold residuals.

GitHub effort proxy limitation

At most 1,200 commits are sampled per repository, approximately 60 author-months. Predictions above that cap are extrapolations and have not been validated.

Your Data

No accuracy is promised before data is supplied. The app validates CSV/XLSX schemas and provides a template; training is intentionally disabled until completed-project outcomes and sufficient sample size are available.
